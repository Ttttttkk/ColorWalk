# 收集世界的颜色 - 需求文档

## 项目目标

制作一个纯前端小网站，让用户上传照片后在浏览器本地生成对应色卡，并导出一张排版好的成果图。项目暂不使用后端，不上传用户图片。

## 技术要求

- 使用 HTML、CSS、JavaScript 实现。
- 不使用后端服务。
- 第一版不需要安装依赖。
- 图片处理、色卡提取和 PNG 导出都在浏览器本地完成。

## 视觉风格

- 页面风格简洁、轻盈。
- 整体偏奶油色系和 ins 风。
- 首页不做营销落地页，打开就是工具本身。
- 照片是第一视觉主角，色卡作为温柔的补充信息。

## 核心功能

1. 用户可以点击按钮上传 JPG 或 PNG。
2. 用户可以拖拽 JPG 或 PNG 到上传区域。
3. 上传后页面显示照片预览。
4. 网站从照片中提取主要颜色。
5. 默认生成 5 个颜色。
6. 用户可以切换色卡数量为 4、5、6。
7. 用户可以进入成果编辑状态。
8. 用户可以导出 PNG 成果图。

## 成果图设置

默认成果图样式：

- 拍立得相纸风白边框。
- 色卡位于照片下方。
- 色卡为圆形。
- 默认不显示 HEX 色值。
- 保留上传照片的完整内容和原始比例，不裁剪画面。
- 不同色卡数量都应通过调整色块大小和间距填满对应边框区域。

用户可以调整：

- 边框样式：拍立得、侧边框、下边框。
- 白边大小：小、中、大。
- 色卡位置：下方、右侧、左侧。
- 色卡形状：圆形、方形。
- 是否显示 HEX 色值。
- 色卡数量：4、5、6。

## 异常处理

网站需要处理：

- 不支持的文件类型。
- 图片加载失败。
- 无法识别颜色。
- PNG 导出失败。

提示文案应简短、友好。

## 验收标准

- 可以直接打开 `index.html` 使用。
- JPG 和 PNG 上传可用。
- 拖拽上传可用。
- 色卡会显示在照片下方。
- 所有输出设置都会实时更新成果预览。
- 下载按钮可以生成 PNG。
- 页面在桌面端和移动端宽度下都可用。
